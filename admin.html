Rating Adjustments

Sets a player's rating to the value entered. Dated the current work day (07:30–07:30 Kyiv time), it takes effect when saved: that day's earlier results still count with the old rating, later ones build on the new value. Dated another day, it takes effect at 07:30, the start of that work day. Earlier history is kept; this is not a reset. Monthly resets are not listed here; they are managed in the Monthly Reset tab.
